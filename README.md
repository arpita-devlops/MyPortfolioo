# Arpita Pandey — Portfolio

Software engineer building full-stack and AI-powered applications. This is my personal site: an interactive 3D portfolio covering my experience, projects, skills and certifications.

**Live site:** https://arpita-devlops.github.io/MyPortfolioo/

## Highlights

- **3D particle background** (Three.js) that morphs into a different shape for each section, so the background changes as you scroll.
- **Light and dark themes**, switched with a circular reveal animation.
- **Real project previews**: screenshot carousels with a full-screen gallery for each project.
- **Responsive and accessible**: works on mobile, supports keyboard navigation and respects reduced-motion settings.
- **No build step**: plain HTML, CSS and JavaScript, hosted on GitHub Pages.
